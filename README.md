# capacity-planning-optimization

A Python utility for optimizing Business-As-Usual (BAU) work allocation using linear programming with priority-based scheduling flexibility and resource theme management.

## Features

- **Priority-Based Flexibility**: High (cannot move), Medium (3-month window), Low (6-month window)
- **Resource Theme Management**: Skill-based resource allocation across different work themes
- **Cadence Optimization**: Maintains operational rhythm while minimizing resource gaps
- **Visual Analytics**: Comprehensive dashboards showing current vs optimized schedules
- **Gap Analysis**: Identifies resource shortages and surpluses with actionable insights
